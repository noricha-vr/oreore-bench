### レベル2: 配列・順序・真偽値

本文について次の4項目を答え、下のスキーマの JSON で出力してください。

```json
{
  "people": [""],
  "years_mentioned": [0],
  "grandfather_alive_at_writing": false,
  "tools": [""]
}
```

- `people`: 本文（冒頭の題名・著者名の行を除く）に人名で登場する人物を**初出順に全員**。名字は除き、下の名前で書く（カタカナ名はそのまま）。同一人物は初出の1回のみ数える
- `years_mentioned`: 本文に西暦で登場する年を**すべて、昇順・重複なし**で（数値）。温度・年数・年齢は含めない
- `grandfather_alive_at_writing`: この文章の執筆時点で祖父が存命なら true、故人なら false
- `tools`: 工房の壁に掛かっていた三つの道具を、本文の記載順に
