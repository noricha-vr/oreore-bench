### レベル4: 文字列の忠実な抽出

本文について次の3項目を答え、下のスキーマの JSON で出力してください。

```json
{
  "quotes": [
    { "speaker": "", "text": "" }
  ],
  "english_phrase": "",
  "letter_excerpt": ""
}
```

- `quotes`: 鉤括弧「」で直接括られた発話を、本文の**出現順にすべて**並べる
  - `speaker`: 発話者の下の名前
  - `text`: 「」の内側を**一字一句そのまま**（句読点・『』も保つ。外側の「」自体は含めない）
  - 他の人物の発話の中で『』により引用された言葉は、独立した発話として数えない
- `english_phrase`: マルコが書き残した英文を、**前後の引用符 " を含めて**一字一句そのまま
- `letter_excerpt`: 祖父の手紙の本文3行を、行頭の引用記号（>）を除き、**改行をそのまま保って**1つの文字列にする（JSON 文字列内の改行は \n）
