### レベル5: 文書全体の構造化

本文全体を、下のスキーマの JSON に構造化してください。

```json
{
  "meta": {
    "title": "",
    "author": "",
    "section_count": 0
  },
  "characters": [
    {
      "name": "",
      "kinship_to_narrator": "",
      "relations": [
        { "to": "", "relation": "" }
      ]
    }
  ],
  "timeline": [
    { "year": 0, "sentence": "" }
  ],
  "process": {
    "melting_temperature_c": 0,
    "steps": [
      { "order": 0, "name": "", "temperature_c": 0 }
    ]
  },
  "quotes_by_speaker": {
    "宗一郎": [""],
    "綾乃": [""]
  },
  "analysis": {
    "grandfather_last_words": "",
    "narrator_became_glassblower": false
  }
}
```

- `meta.title` / `meta.author`: 題名と著者名。`meta.section_count`: 節の数（数値）
- `characters`: 本文（冒頭の題名・著者名の行を除く）に人名で登場する人物を**初出順に全員**（名字は除き下の名前、カタカナ名はそのまま）
  - `kinship_to_narrator`: 語り手から見た続柄。`"self"` | `"grandfather"` | `"grandmother"` | `"elder_sister"` | `"none"` のいずれか
  - `relations`: 家族関係**以外**で本文に明記された関係のみを `{ "to": 相手の下の名前, "relation": ... }` で列挙する。`relation` は `"apprentice"` | `"master"` | `"spouse"` | `"sibling"` のいずれかで、「この人物が to の人物に対して何であるか」を表す（例: A が B の弟子なら A 側に `{ "to": "B", "relation": "apprentice" }`）。該当がない人物は空配列 `[]`
- `timeline`: 本文に西暦で登場する年を**昇順にすべて**並べる
  - `year`: 西暦年（数値）
  - `sentence`: その年号を含む一文を**一字一句そのまま**
- `process.melting_temperature_c`: 硝子種が溶ける温度（数値）
- `process.steps`: 五つの工程を本文の順に
  - `order`: 1〜5 の数値
  - `name`: 工程名
  - `temperature_c`: その工程に温度が本文で明記されていれば数値、なければ null
- `quotes_by_speaker`: 鉤括弧「」で直接括られた発話を、話者別に出現順で並べる（「」の内側を一字一句そのまま）。キーは `"宗一郎"` と `"綾乃"` の2つ。他の発話の中で『』により引用された言葉は含めない
- `analysis.grandfather_last_words`: 祖父の最期の言葉が本文に書かれていればその抜き出し、書かれていなければ null
- `analysis.narrator_became_glassblower`: 語り手が硝子職人になったなら true、ならなかったなら false
