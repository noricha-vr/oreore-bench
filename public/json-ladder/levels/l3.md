### レベル3: ネスト・enum・null

本文について次の2項目を答え、下のスキーマの JSON で出力してください。

```json
{
  "sections": [
    { "heading": "", "season": "" }
  ],
  "workshop": {
    "name": "",
    "founded_year": 0,
    "closed_year": 0
  }
}
```

- `sections`: 4つの節すべてを本文の順に並べる
  - `heading`: 見出しから先頭の漢数字と空白を除いた表題（例: 見出しが「五 春の窯」なら「春の窯」）
  - `season`: その節に明示されている季節。`"spring"` | `"summer"` | `"autumn"` | `"winter"` のいずれか。季節の記述がない節は `"none"`
- `workshop.name`: 工房の名前
- `workshop.founded_year`: 工房を構えた西暦年（数値）
- `workshop.closed_year`: 工房を畳んだ西暦年が本文に**明記されていれば**その数値、明記されていなければ null（推測しない）
