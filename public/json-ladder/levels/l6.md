### レベル6: 全文の逐語インデックス

本文を、下のスキーマの JSON に構造化してください。**本文の表記を写す指示のあるフィールドは、句読点・記号・送り仮名まで一字一句そのまま**にしてください。

```json
{
  "sections": [
    {
      "index": 0,
      "number_kanji": "",
      "heading": "",
      "first_sentence": "",
      "last_sentence": "",
      "paragraph_count": 0,
      "sentence_count": 0,
      "paragraph_openings": [""],
      "has_direct_quote": false,
      "years": [0]
    }
  ],
  "claims": [
    { "id": "", "verdict": "", "evidence": "" }
  ],
  "stated_facts": [
    { "id": "", "value": 0, "stated": false }
  ],
  "counts": {
    "sections": 0,
    "direct_quotes": 0,
    "letter_lines": 0,
    "years_in_text": 0
  }
}
```

- `sections`: 4つの節すべてを本文の順に
  - `index`: 1 から始まる連番（数値）
  - `number_kanji`: 見出しの先頭の漢数字だけ（例: 見出しが「一 炎の温度」なら `"一"`）
  - `heading`: 見出しから先頭の漢数字と空白を除いた表題（例: `"炎の温度"`）
  - `first_sentence`: その節の**本文の最初の一文**を一字一句そのまま（見出し行は含めない。句点「。」までを1文とする。鉤括弧「」だけの行も1文として数える。手紙の引用行（>）も1文として数える）
  - `last_sentence`: その節の**本文の最後の一文**を同じ規則で一字一句そのまま
  - `paragraph_count`: その節に含まれる段落の数（空行で区切られたかたまり。見出し行は含めない。鉤括弧「」だけの行も1段落として数える。手紙の引用（>）3行はまとめて1段落と数える）
  - `sentence_count`: その節に含まれる文の数（`first_sentence` と同じ数え方）
  - `paragraph_openings`: その節の**各段落の最初の一文**を、段落の順に並べる（`first_sentence` と同じ数え方で一字一句そのまま）。件数は `paragraph_count` と一致する
  - `has_direct_quote`: その節に鉤括弧「」で直接括られた発話があれば true
  - `years`: その節に西暦で登場する年を昇順・重複なしで（数値）。1つもなければ空配列 `[]`
- `claims`: 下の 4 つの主張それぞれについて、本文の記述だけで判定する。順序は下の並びのとおり
  - `verdict` は次の3つのいずれか
    - `"stated"`: 本文が事実として断定している
    - `"speculated"`: 本文が語り手の推量・伝聞として書いている（「〜と思う」「〜らしい」「〜かもしれない」など）
    - `"absent"`: 本文にその主張についての記述が一切ない
  - `evidence`: `"stated"` または `"speculated"` の場合、判断の根拠を含む**一文まるごと**を一字一句そのまま（句点「。」まで含める）。`"absent"` の場合は null
  - 判定する主張:
    - `grandfather_wanted_sister_as_successor`: 祖父は姉に工房を継がせたがっていた
    - `grandmother_mediated_between_sister_and_grandfather`: 祖母は姉と祖父のあいだを取り持っていた
    - `sister_moved_away_from_the_city`: 姉は富山市を離れて暮らすようになった
    - `narrator_did_not_become_glassblower`: 語り手は硝子職人にならなかった
- `stated_facts`: 下の 5 つの `id` について、**本文にその数量が書かれていれば**（算用数字でも漢数字でもよい） `stated` を true にして `value` にその数値を入れ、**書かれていなければ** `stated` を false にして `value` を null にする。他の記述から差を計算すれば求まる値でも、その数量自体が本文に書かれていなければ false・null とする。順序は下の並びのとおり
  - `melting_temperature_c`: 硝子種が溶ける温度
  - `workshop_founded_year`: 工房を構えた西暦年
  - `workshop_closed_year`: 工房を畳んだ西暦年
  - `grandfather_years_at_the_kiln`: 祖父が窯の前に立ち続けた年数
  - `sister_age_gap_to_narrator`: 姉と語り手の年齢差
- `counts`: それぞれの個数（数値）
  - `sections`: `##` の節の数
  - `direct_quotes`: 鉤括弧「」で直接括られた発話の数（他の発話の中で『』により引用されたものは数えない）
  - `letter_lines`: 祖父の手紙の引用（>）の行数
  - `years_in_text`: 西暦で登場する年の種類数（重複を除く）
