json-ladder プロンプト

長文随筆から、レベル1〜5 の段階的なスキーマで JSON を抽出させる書式遵守テスト。

役割

あなたは日本語の文章読解と構造化データ抽出を行うアシスタントです。下記の随筆を読み、設問が指定する JSON スキーマに厳密に従って回答してください。

共通ルール

  • 指定された JSON を単体で出力する（前後に説明文不要）
  • スキーマに示されたキー構成に厳密に従う。キーの追加・省略・改名は不可
  • 「一字一句そのまま」の指示があるフィールドは、本文の表記を句読点まで含めて正確に写す
  • 数値は JSON の数値型で、真偽値は true / false で出力する（文字列にしない）
  • 本文に明記されていない値は JSON の null とする（文字列 "null" やキーの省略は不可）
  • 配列の順序・件数は各設問の指示に従う

レベル1: フラットな基本情報

本文について次の4項目を答え、下のスキーマの JSON で出力してください。

{
  "title": "",
  "author": "",
  "founded_year": 0,
  "city": ""
}
  • title: この随筆の題名
  • author: 著者名
  • founded_year: 祖父が工房を構えた西暦年（数値）
  • city: 工房があった市の名前

レベル2: 配列・順序・真偽値

本文について次の4項目を答え、下のスキーマの JSON で出力してください。

{
  "people": [""],
  "years_mentioned": [0],
  "grandfather_alive_at_writing": false,
  "tools": [""]
}
  • people: 本文（冒頭の題名・著者名の行を除く）に人名で登場する人物を初出順に全員。名字は除き、下の名前で書く（カタカナ名はそのまま）。同一人物は初出の1回のみ数える
  • years_mentioned: 本文に西暦で登場する年をすべて、昇順・重複なしで（数値）。温度・年数・年齢は含めない
  • grandfather_alive_at_writing: この文章の執筆時点で祖父が存命なら true、故人なら false
  • tools: 工房の壁に掛かっていた三つの道具を、本文の記載順に

レベル3: ネスト・enum・null

本文について次の2項目を答え、下のスキーマの JSON で出力してください。

{
  "sections": [
    { "heading": "", "season": "" }
  ],
  "workshop": {
    "name": "",
    "founded_year": 0,
    "closed_year": 0
  }
}
  • sections: 4つの節すべてを本文の順に並べる
    • heading: 見出しから先頭の漢数字と空白を除いた表題（例: 見出しが「五 春の窯」なら「春の窯」）
    • season: その節に明示されている季節。"spring" | "summer" | "autumn" | "winter" のいずれか。季節の記述がない節は "none"
  • workshop.name: 工房の名前
  • workshop.founded_year: 工房を構えた西暦年（数値）
  • workshop.closed_year: 工房を畳んだ西暦年が本文に明記されていればその数値、明記されていなければ null（推測しない）

レベル4: 文字列の忠実な抽出

本文について次の3項目を答え、下のスキーマの JSON で出力してください。

{
  "quotes": [
    { "speaker": "", "text": "" }
  ],
  "english_phrase": "",
  "letter_excerpt": ""
}
  • quotes: 鉤括弧「」で直接括られた発話を、本文の出現順にすべて並べる
    • speaker: 発話者の下の名前
    • text: 「」の内側を一字一句そのまま（句読点・『』も保つ。外側の「」自体は含めない）
    • 他の人物の発話の中で『』により引用された言葉は、独立した発話として数えない
  • english_phrase: マルコが書き残した英文を、前後の引用符 " を含めて一字一句そのまま
  • letter_excerpt: 祖父の手紙の本文3行を、行頭の引用記号（>）を除き、改行をそのまま保って1つの文字列にする（JSON 文字列内の改行は \n）

レベル5: 文書全体の構造化

本文全体を、下のスキーマの JSON に構造化してください。

{
  "meta": {
    "title": "",
    "author": "",
    "section_count": 0
  },
  "characters": [
    {
      "name": "",
      "kinship_to_narrator": "",
      "relations": [
        { "to": "", "relation": "" }
      ]
    }
  ],
  "timeline": [
    { "year": 0, "sentence": "" }
  ],
  "process": {
    "melting_temperature_c": 0,
    "steps": [
      { "order": 0, "name": "", "temperature_c": 0 }
    ]
  },
  "quotes_by_speaker": {
    "宗一郎": [""],
    "綾乃": [""]
  },
  "analysis": {
    "grandfather_last_words": "",
    "narrator_became_glassblower": false
  }
}
  • meta.title / meta.author: 題名と著者名。meta.section_count: 節の数（数値）
  • characters: 本文（冒頭の題名・著者名の行を除く）に人名で登場する人物を初出順に全員（名字は除き下の名前、カタカナ名はそのまま）
    • kinship_to_narrator: 語り手から見た続柄。"self" | "grandfather" | "grandmother" | "elder_sister" | "none" のいずれか
    • relations: 家族関係以外で本文に明記された関係のみを { "to": 相手の下の名前, "relation": ... } で列挙する。relation は "apprentice" | "master" | "spouse" | "sibling" のいずれかで、「この人物が to の人物に対して何であるか」を表す（例: A が B の弟子なら A 側に { "to": "B", "relation": "apprentice" }）。該当がない人物は空配列 []
  • timeline: 本文に西暦で登場する年を昇順にすべて並べる
    • year: 西暦年（数値）
    • sentence: その年号を含む一文を一字一句そのまま
  • process.melting_temperature_c: 硝子種が溶ける温度（数値）
  • process.steps: 五つの工程を本文の順に
    • order: 1〜5 の数値
    • name: 工程名
    • temperature_c: その工程に温度が本文で明記されていれば数値、なければ null
  • quotes_by_speaker: 鉤括弧「」で直接括られた発話を、話者別に出現順で並べる（「」の内側を一字一句そのまま）。キーは "宗一郎" と "綾乃" の2つ。他の発話の中で『』により引用された言葉は含めない
  • analysis.grandfather_last_words: 祖父の最期の言葉が本文に書かれていればその抜き出し、書かれていなければ null
  • analysis.narrator_became_glassblower: 語り手が硝子職人になったなら true、ならなかったなら false

入力（本文）

本文は 入力本文ビュー または input.md を参照。各レベルの設問と本文を組み合わせて 1 リクエストずつ、計 5 回投げる。
