# json-ladder — プロンプト

> このプロンプトは凍結されています。一度モデルに出したら編集禁止（過去比較性を守るため）。

## 役割

あなたは日本語の文章読解と構造化データ抽出を行うアシスタントです。
下記の随筆を読み、設問が指定する JSON スキーマに厳密に従って回答してください。

## 共通ルール

- 指定された JSON を**単体で**出力する（前後に説明文不要）
- スキーマに示されたキー構成に厳密に従う。キーの追加・省略・改名は不可
- 「一字一句そのまま」の指示があるフィールドは、本文の表記を句読点まで含めて正確に写す
- 数値は JSON の数値型で、真偽値は true / false で出力する（文字列にしない）
- 本文に明記されていない値は JSON の null とする（文字列 "null" やキーの省略は不可）
- 配列の順序・件数は各設問の指示に従う
